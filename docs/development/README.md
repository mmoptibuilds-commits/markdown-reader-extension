# Development notes

Use this directory for durable project context that a future contributor or coding agent would otherwise need to rediscover:

- significant implementation or architecture decisions;
- major feature progress and its verified checks;
- unresolved technical concerns and their current status.

For a useful update, create a dated file such as `YYYY-MM-DD-short-topic.md`. Record the context, decision or change, files/systems affected, commands actually run and their results, and remaining work. Distinguish verified facts from assumptions. Link related issues or pull requests when they exist.

Do not create an entry for routine edits or duplicate the full README. Keep `CLAUDE_HANDOFF.md` as the current concise project snapshot and update it when that baseline materially changes. The skill inventory and Codex/Claude mirror process belong in `.agents/skills/skills-manifest.md`.
